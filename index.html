jerry-dev

An AI Agent integration tool designed to connect AI assistants with Google Workspace services for streamlined schedule and email management.

1. Application Purpose (應用程式用途)

jerry-dev is a productivity integration application that enables AI agents to securely connect with a user's Google services upon explicit authorization. Through natural language instructions, users can empower their AI agent workflows to look up daily schedules, manage calendar events, and handle routine email tasks efficiently.

2. Google Services & Data Usage (連接的 Google 服務與資料用途)

To deliver these AI agent capabilities, jerry-dev connects exclusively to the following Google services via Google OAuth 2.0:

  • Google Calendar: Used by the AI agent to read upcoming events, check schedule availability, and create, update, or organize calendar events based on user commands.
  • Gmail: Used by the AI agent to search, read, draft, and manage email messages strictly upon the user's explicit request to assist with inbox workflows.

All data retrieved through Google APIs is processed in real time solely to execute the user's requested AI agent tasks. jerry-dev does not sell user data, use it for advertising, or share it with unauthorized third parties.

Google API Services User Data Policy Compliance:
jerry-dev's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
